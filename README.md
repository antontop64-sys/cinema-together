# Cinema Together — MVP совместного просмотра

Комната для двух человек без регистрации. Организатор показывает экран и, если браузер разрешает, звук выбранной вкладки. В режиме «Смотреть и общаться» оба участника также могут включать и выключать микрофон.

## Что нужно

- Node.js 18 или новее
- современный Chrome, Edge, Firefox или Safari
- для просмотра через интернет — HTTPS-домен (доступ к экрану и микрофону браузеры дают только на HTTPS или `localhost`)

## Запуск

```bash
npm start
```

Откройте `http://127.0.0.1:4173` в двух окнах браузера. В первом создайте комнату, во втором откройте скопированную ссылку. Для другого порта:

```bash
PORT=8080 npm start
```

## Проверка

```bash
npm test
```

## Как это устроено

- медиапотоки идут напрямую между браузерами через WebRTC;
- небольшой signaling server передаёт SDP и ICE-кандидаты через короткие HTTP-запросы;
- сервер хранит комнаты только в памяти, поэтому после перезапуска они закрываются;
- комната ограничена двумя активными участниками и автоматически очищается после бездействия;
- публичный STUN-сервер помогает установить прямое соединение между разными сетями.

Для production-развёртывания запустите этот Node.js-сервис за HTTPS reverse proxy. Для сетей со строгим NAT потребуется добавить TURN-сервер в `iceServers` внутри `public/app.js`.

На сервере или в контейнере разрешите внешние подключения:

```bash
HOST=0.0.0.0 PORT=8080 npm start
```

## Ограничение DRM

Netflix, Кинопоиск и другие сервисы с DRM могут блокировать захват изображения или звука. В таком случае браузер покажет чёрный экран — это ограничение платформы, а не ошибка приложения.
